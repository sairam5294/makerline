# UX copy checklist

Use for the "Content and voice" step and to review any screen's words. Each line is a pass/fail check; fix fails before handoff.

## Every piece of copy

- [ ] Says what happens, in the user's words (the terminology list), not the system's ("Payment didn't go through", not "Transaction error 402").
- [ ] Front-loads the important word; ≤ 2 short sentences; no jargon, no blame, no exclamation marks in errors.
- [ ] Same word for the same thing everywhere (one term per concept).
- [ ] Reads well aloud and with a screen reader; makes sense at 200% text and when truncated.
- [ ] Works when translated: no idioms or puns, room for +30% length, no text in images, dates and money in the user's locale.

## By moment

| Moment | Must include | Example |
|---|---|---|
| **Button / CTA** | a verb + object for what it does | "Save expense", not "Submit" |
| **Error** | what went wrong · why if useful · how to fix · keeps their input | "That code has expired. We've sent a new one to 98••••21." |
| **Empty state** | why it's empty · the one next action · no guilt | "No expenses yet. Add your first one — it takes 10 seconds." |
| **Confirmation (destructive)** | the exact consequence · a specific button label · undo if possible | "Delete 3 expenses? This can't be undone." [Delete 3] [Cancel] |
| **Loading / waiting** | what's happening if it takes > 2 s; cancel for long tasks | "Reading your receipt…" |
| **Success** | what changed · what's next, briefly | "Saved. View this month's total" |
| **Permission ask** | why, in the user's benefit, before the system prompt | "Allow notifications so we can remind you on salary day." |
| **Onboarding promise** | the outcome, not the features | "See where your money goes in a week." |
| **AI output** | labelled as AI · how to edit or undo · what it can get wrong | "Suggested by AI — check the amount." |
